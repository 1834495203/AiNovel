# 会话记录与操作

独立的「作品运行历史」页面及导航已移除。创作访谈、写幕、故事讨论、角色访谈各自在会话中展示逐轮执行记录；最新消息下提供回退、重新生成、修改、删除和失败重试。旧消息不提供操作按钮。后端命令、事件和版本作为回退凭据继续保存，撤回后的消息不进入后续模型上下文。

写幕仍是一部小说一条连续的创作会话，可按章节和幕筛选。资料编辑从小说工作区进入，独立故事资料页只读。写作中的资料修改、角色审批、草稿修改和确认均使用原有持久撤回凭据；回退和删除恢复关联业务状态，重新生成及修改先回退原操作再提交新命令。提交失败时保留待提交输入和已撤回状态，避免重复回退。

故事讨论只讨论和查询前文，不修改世界观、人物、偏好、计划、字段或正文。模型只获得 `search_story` 工具；解码器和业务处理器都拒绝修改工具，旧提示词无法绕过限制。角色访谈同样不修改小说。它们按各自会话保存撤回栈，回退只影响该会话的对话，不移动小说版本指针、不影响其他会话，也不阻塞写幕撤回。旧版会修改资料的讨论记录仍需按原有写作操作顺序回退，避免覆盖后续事实。

已提交正文的幕及其章节字段禁止编辑，应用新模板也不覆盖这些已锁定字段。该轮末尾隐藏修改设定入口，只提供文本重新生成；确认操作先回退正文和关联资料，随后复用原有设定和规划修订正文。`text_only` 在后端强制关闭重新规划、新角色引入和额外角色访谈，且随草稿检查点保留。新正文仍需要用户确认后提交。

展开执行记录、切换页面等操作不进入撤回栈。删除消息是可追溯的业务回退，不清除审计凭据；整部小说的永久删除仍会清除全部关联记录。
