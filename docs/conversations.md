# 会话记录与操作

独立的作品运行历史页面已移除。创建小说、幕设定、普通讨论、角色对话分别保存自己的消息和执行记录；最新消息提供回退、重新生成、修改、删除和失败重试。后端命令、事件和小说版本用于恢复关联业务状态，撤回消息不进入后续模型上下文。

幕设定允许用户开启多个会话，一轮可批量创建或修改多个未写作的幕、创建分支。它直接执行工具并保存设定，没有正文草稿或自动角色审批。多个会话提交时检查小说版本，防止覆盖并发修改。

正文模式按当前路线的下一幕写作，必须先有幕计划。生成和修改共用同一个正文 agent；用户确认后提交正文、角色事实变化和相关资料，确认与放弃均不调用模型。已经写出正文的幕及其章节设定锁定，只能重写正文。

普通讨论允许查询前文及资料，不修改小说；角色对话只使用选定时点的角色资料和经历。它们按各自会话保存撤回栈，回退对话不移动小说版本指针。

回退、删除恢复关联业务状态；重新生成及修改先回退原操作再提交。小说修改按操作顺序撤回，避免覆盖后续修改。展开执行记录和切换页面不进入撤回栈。整部小说永久删除会清除全部关联记录。
